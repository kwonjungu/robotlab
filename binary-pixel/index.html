이진수·픽셀 신호

컴퓨터는 그림을 0(꺼짐)과 1(켜짐)만으로 나타내요. 칸을 켜고 끄면 그림이 나타나죠. 도트 매트릭스와 픽셀의 원리예요. 코드를 보고 그림을 그리거나, 내가 그린 그림을 0·1 코드로 읽어 봐요.

알아 둬요 — 픽셀 하나는 0 아니면 1, 딱 두 가지 상태예요. 이렇게 0과 1만 쓰는 수를 이진수라고 해요. 한 줄을 이진수로 읽으면 십진수로도 바꿀 수 있어요(예: 00100 → 4). 그림·글자·소리까지 결국 컴퓨터 안에서는 모두 0과 1로 저장돼요.
