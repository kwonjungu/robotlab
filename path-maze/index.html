명령 서랍 (클릭하거나 아래로 끌어다 놓기)

「반복」은 바로 앞 명령 1개를 정한 횟수만큼 되풀이해요. 「전진 · 반복 4회」는 전진을 4번 한 것과 같아요. 항목의 + / −로 횟수를 바꿔요.

내 명령0 개
  • 여기에 명령이 쌓여요

먼지를 다 지나기만 하면 성공이에요. 같은 방향으로 여러 칸 가야 할 땐 반복으로 명령을 확 줄일 수 있어요.

알고리즘이란 — 먼지를 다 지나는 길은 여러 가지예요. 그중 이동 칸수가 적은 길을 찾는 게 좋은 알고리즘이에요. 지그재그로 훑거나, 한 줄씩 왕복하는 방법을 떠올려 봐요. 그리고 반복을 쓰면 명령 개수도 줄어들어요.

스스로 점검

  • 먼지를 모두 지나는 경로를 머릿속으로 그린 뒤 명령을 짤 수 있다.
  • 같은 방향 이동을 반복으로 묶어 명령 개수를 줄일 수 있다.
  • 같은 청소라도 이동 칸수가 적은 길이 더 좋은 알고리즘임을 안다.
